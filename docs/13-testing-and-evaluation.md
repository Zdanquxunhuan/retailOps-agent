# 13 测试与 Agent 评估

## 数据集设计

拟建立脱敏 JSONL 故障集，每条包含 caseId、scenario、input、authorizedScope、fixtures、expectedIntent、requiredEvidence、expectedRootCause、allowedActions、expectedPosStates、knowledgeVersion。事实标签由业务负责人复核，模型不能自标为黄金答案。

初版美团销售至少 60 例：40 例调优/开发、20 例冻结测试；同一订单或相同故障模板变体在同一分组，避免泄漏。完整五场景目标至少 200 例，每场景至少 30 例，补充安全与跨场景异常。初轮只定义数据集设计，未创建真实测试样本、未运行效果评估。

| 故障/边界 | 应有行为 |
|---|---|
| 本地无日志但平台有单 | 说明接收未证实与日志覆盖，不直接归罪平台 |
| 平台窗口外 / 边界 / 未知订单时间 | 不作无效调用；明确缺参或超窗 |
| 平台空结果但分页未完成 | PARTIAL，不宣称平台不存在订单 |
| 数据库异常、校验错误、POS 业务拒绝 | 各自证据与规则映射，不混成网络问题 |
| HTTP 200 但业务失败 | 接口与业务分层报告 |
| POS 已接收、处理未知 / 待过账 | 明确未知或门店下一步，禁止重复补推 |
| 多实例部分不可达、轮转丢失、日志乱序 | 覆盖不足与时钟误差提示 |
| 退货多事件 / 原单已推但退货未推 | 使用独立业务身份，不能以原单成功结束 |
| 税率任务漏跑、分页断点、部分成功 | 定位任务阶段，不能直接重跑整批 |
| 请求已发送后崩溃或超时 | UNKNOWN，恢复先查状态 |

## 测试层次

- Tool 单元/契约：Schema、范围、状态映射、分页、限流、超时、脱敏、覆盖语义。
- Workflow：状态迁移、节点恢复、预算耗尽、取消、重复调度、并发竞争。Mock 外部响应，不用真实订单。
- 安全：直接调用执行接口、跨租户/门店/环境、审批过期/自批/撤权/改参、日志与 RAG 注入、SSRF、路径逃逸。
- 幂等：并发 20 个相同业务请求，模拟接收前后宕机、数据库提交失败、下游最终一致与延迟核验。分别验证有/无下游幂等能力时的处理。
- 集成：Testcontainers PostgreSQL/pgvector（Docker 可用后），验证唯一约束、CAS、审批消费、索引过滤；HTTP stub 验证真正序列化契约。
- 端到端：用户输入 → 工具 → 报告 → 测试环境审批补推 → POS 核验；普通 contextLoads 不能代替。

## 指标、分母与门槛（提议值）

| 指标 | 定义 | 初始验收目标 |
|---|---|---|
| 意图路由准确率 | 正确平台+业务类型 / 可判定输入 | ≥95% |
| 必填槽位准确率 | 完全正确提取或正确追问 / 全部输入 | ≥95% |
| 工具选择准确率 | 当前步骤选取允许且必要工具 / 已标注选择点 | ≥95%，越权工具实际执行 0 |
| 根因 Macro-F1 | 各故障类别 F1 宏平均，含证据不足类 | ≥0.85，同时报告每类结果 |
| 无依据确定结论率 | 无证据却断言事实的报告 / 全部报告 | ≤2%；高风险成功结论误报 0 |
| RAG Recall@5 | top5 覆盖的相关段落 / 标注相关段落 | ≥0.85 |
| 引用正确率 | 支持对应主张且可访问的引用 / 全部引用 | ≥95%，不存在的引用 0 |
| 隔离/重复写入 | 测试集中越权执行/重复业务创建数 | 均为 0 |
| 性能 | 10 并发、规定 Mock 延迟下端到端 p95 | 目标 ≤60 秒；公开夹具与硬件 |

以上均非已达成绩。冻结集只有 20 例时必须同时报告“正确数/总数”，不可用漂亮百分比掩盖不稳定性。每个模型/Prompt 版本在同一冻结集重复至少 3 次，保存版本、参数、知识快照、工具夹具和运行日期；模型漂移需重新跑基线。

比较规则-only、LLM+固定取证、LLM+受限动态取证、再加 RAG 四组，报告质量、工具次数、延迟、token 和人工确认数。LLM-as-judge 只能辅助，最终事实、权限和副作用由确定性断言及人工复核判断。阶段 8 压测与故障注入通过后才考虑生产试点。
